## Hue color ranges

**Approximate Hue Ranges**

These are guidelines, NOT rules.

| Color | Approx Hue Range (OpenCV) |
| :--- | :--- |
| **Red** | 0–10 and 170–179 |
| **Orange** | 10–25 |
| **Yellow** | 25–35 |
| **Green** | 35–85 |
| **Cyan** | 85–100 |
| **Blue** | 100–140 |
| **Purple / Magenta** | 140–170 |
